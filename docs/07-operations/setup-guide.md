# Setup guide

Owner: Jemma Santiago
Last updated: 2026-10-15

## Prerequisites

* A Databricks workspace with Unity Catalog enabled.
* A service principal or personal account with `CREATE CATALOG` and `USE CATALOG` permissions.
* Access to the landing volume: `/Volumes/workspace/default/ftw-b12-de/groups/g5_landing`.
* Git CLI and the `databricks` CLI installed locally.
* Python 3.11+ for local checks.

## Local setup

```bash
# Clone the repository
git clone https://github.com/FTW-Dengue-rous/philippine-public-health-platform.git
cd philippine-public-health-platform

# Install dependencies
pip install -r requirements-dev.txt

# Set up pre-commit hooks
pre-commit install
```

## Databricks setup

### 1. Authenticate the Databricks CLI

```bash
databricks auth login --host https://<your-workspace>.cloud.databricks.com
```

### 2. Deploy the bundle

```bash
# Deploy to dev target (personal copy)
databricks bundle deploy -t dev

# Deploy to prod (requires prod permissions)
databricks bundle deploy -t prod
```

The bundle deploys:
* `src/` and `config/` to the workspace root.
* The pipeline job (`ph_public_health_pipeline`) and setup job.
* Excludes `archive/`, `docs/`, `data/`, `tests/`, `dashboard/`, `presentation/`, and ingestion notebooks.

### 3. Create the catalog and schemas

The pipeline job's first task runs the setup job, which creates the `public_health` catalog and `bronze`, `silver`, `gold`, `quality` schemas if they do not exist. You can also run it manually:

```sql
-- src/00_setup/schema_setup.sql
CREATE CATALOG IF NOT EXISTS public_health;
CREATE SCHEMA IF NOT EXISTS public_health.bronze;
CREATE SCHEMA IF NOT EXISTS public_health.silver;
CREATE SCHEMA IF NOT EXISTS public_health.gold;
CREATE SCHEMA IF NOT EXISTS public_health.quality;
```

Quality tables are created by `src/00_setup/quality_setup.sql`.

### 4. Landing data

Source files must be placed in the landing volume manually or by the ingestion notebooks:

* PSGC: run `src/01_ingestion/psgc_ingestion` notebook.
* Admin boundaries: run `src/01_ingestion/admin_boundaries_ingestion` notebook.
* Other sources: download from provider URLs and place in the correct landing folder per the YAML config.

## Configuration

Source configs are YAML files in `config/`:

* `sources_geography.yaml` — PSGC and admin boundaries.
* `sources_facilities.yaml` — 15 facility sources.
* `sources_diseases.yaml` — disease sources.
* `sources_workforce.yaml` — workforce sources.
* `sources_socioeconomic.yaml` — socioeconomic sources.
* `sources_population.yaml` — population (part of geography).

Reference CSVs are in `config/reference/` and generated by `builders/` scripts (run by hand).
