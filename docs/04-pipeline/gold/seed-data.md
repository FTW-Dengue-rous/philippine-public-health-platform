# Seed data

Owner: LUNASaan Documentation Team
Last updated: 2026-10-15

Seed tables are reviewed reference data that the gold layer depends on but that are not derived from silver tables. They encode team decisions and reviewed mappings.

## `source_priority`

* **Script**: `gold_v2_41_source_priority.sql`
* **Purpose**: When multiple sources cover the same metric for the same area and period, `source_priority` stores which source wins. This is a reviewed decision, not derived from data.
* **Grain**: One row per metric x source.
* **Columns**: `metric_name`, `source_key`, `priority_rank` (1 = preferred), `rationale`.

### Rules

| Metric | Preferred source | Alternative | Rationale |
|---|---|---|---|
| Hospital count (current snapshot) | `doh_nhfr_hospitals` | `doh_hfsrb_hospitals` | NHFR is the most comprehensive registry. HFSRB adds licensed facilities not in NHFR. |
| Hospital count (historical) | `psa_hospitals_region_annual` | -- | PSA publishes annual hospital counts by region. |
| Authorized beds (current) | `doh_hfsrb_hospitals` | `doh_nhfr_hospitals` | HFSRB licenses specify bed capacity. NHFR ABC is also used. |
| BHS count (province/city) | `doh_fhsis_demographic` | `psa_bhs_region_annual` | FHSIS covers province/city level. PSA covers region level only, but for longer historical trends. |
| BHS count (region, historical) | `psa_bhs_region_annual` | `doh_fhsis_demographic` | PSA has data from 2006. FHSIS starts at 2018. |
| Dengue cases (region, monthly) | `doh_foi_dengue` | `upnoah`, `hdx_dengue` | FOI is the most complete monthly series. UP NOAH and HDX are weekly. |
| Disease prevalence (province) | `ihme_neoplasm` | `globocan_2024` | IHME GBD provides province-level estimates. GLOBOCAN is national. |
| Workforce headcount (province) | `doh_fhsis_demographic` | `psa_gov_practitioners` | FHSIS covers province/city. PSA covers region only. |
| Poverty incidence | `psa_poverty` | -- | Only source. |

### How it is used

The `fact_default_views` script (gold_v2_44) creates views over each fact table that filter to the preferred source per metric. Dashboard queries read these views instead of the raw fact tables.

### How to update

1. Edit the VALUES list in `gold_v2_41_source_priority.sql`.
2. Rebuild gold (the script is idempotent -- `CREATE OR REPLACE`).
3. Document the change in the script comments and in the [change log](../../08-governance/change-log.md).

## `area_coverage_map`

* **Script**: `gold_v2_42_area_coverage_map.sql`
* **Purpose**: Records which areas each fact table covers. Used by `mart_evidence_readiness` to show where the platform has evidence and where it does not.
* **Grain**: One row per fact table x area.
* **Sources**: All four fact tables (`fact_facility_capacity`, `fact_disease_metric`, `fact_workforce_capacity`, `fact_area_indicator`).
* **Columns**: `fact_table`, `area_key`, `area_name`, `geographic_level`, `row_count`, `latest_period`.

This is not a seed table in the traditional sense -- it is derived from the fact tables. But it serves as a reference for coverage analysis and is built after all facts.

## Named areas in `dim_geography`

The `dim_geography` script includes 7 named areas that do not have PSGC codes:

| area_code | area_name | geographic_level |
|---|---|---|
| `ph` | Philippines | country |
| `foreign` | Foreign country | foreign |
| (5 others) | (named regions for specific source data) | (varies) |

These are reviewed additions to handle source data that does not map to a PSGC code. They are defined as a VALUES list in `gold_v2_11_dim_geography.sql`.

## Reference CSVs in `config/reference/`

The `config/reference/` directory contains reviewed CSV files generated by `builders/` scripts. These are used by silver tables for area name matching, disease name normalization, and similar reference tasks. They are not seed tables in the gold schema, but they serve the same purpose: reviewed, non-derived data that the pipeline depends on.

See `builders/README.md` for how to regenerate these CSVs.
